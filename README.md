## 立项与验收教训

**规格全绿 ≠ 好玩。** 工单前三问：

1. 核心动作是**选择**还是操作？
2. 风险收益是否**同动作绑定**？
3. 去掉核心机制还剩什么动机？

已固化的立项标准见 `structured/game-design/` 的 ideas/ v3/v4：压迫感驱动 / 定价式暴露 / 层级可辨性。
