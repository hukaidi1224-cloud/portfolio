这份指南把结局与全部线索写出来了，介意剧透请先自己走一遍。

文中「」里的词就是画面上能点到的圆点或按钮，照点即可。所有步数都在游戏引擎里实跑验证过。

一、先弄懂这座城的规则

  1. 雨有四种：晴、中雨、暴雨、回南天。路随雨开合，走不通时第一反应是回去换一场雨。
  2. 换雨有两个地方：理发店里那把椅子，以及空街、窗边（这两处也能「等到……」，不必跑回店里）。
  3. 有的路不看天，看你已经知道什么。这类路要用「看」把东西读到手，选项才会出现。
  4. 按 J 或右上角「手账」打开本子。「还在想」最多同时列四条，做完一条会腾出位置；「记下了」是你已经确认的事实，走岔了回来对一眼就知道下一步。定过结局后，本子底部还有「重看结局」，可以再把那段读一遍。

二、地图与天气

能去的地方：湿巷起点 → 理发店 → 店门廊 → 巷中 → 巷尾；深层口外 → 深层口内；城寨口 → 楼梯 1–7 → 七楼转角 → 八楼潮底踏；工地围挡 → 空街 → 窗边 → 无门走廊。

路口什么天气才开额外前提
巷尾 → 城寨口中雨（门洞）／回南天（湿门印）无
城寨口 → 巷尾同上雨换成晴或暴雨，你会被送回店里
七楼转角 → 多出来的一阶中雨先在中雨里点「看踏步」，霉才会指那一阶
深层口外 → 深层口内暴雨无
工地围挡 → 空街中雨无
空街 → 窗边暴雨无
窗边 → 无门走廊任何天气先在窗边点「看窗上的霉」，再点「再在窗边等一场雨」

三、最快走到结尾：11 步（结局＝戴上）

#在哪点什么之后
1湿巷起点「顺着霉花走」进店见陈琛，外面的雨在他开口时变成晴
2理发店「等到中雨」椅子把雨等回来
3理发店「出门」到店门廊
4店门廊「去工地围挡」到围挡
5工地围挡「走进空街」中雨里缺口开着
6空街「等到暴雨」街尽头亮起一条窗缝
7空街「走到窗边」到窗边
8窗边「看窗上的霉」读出「差一场停在这里不散的雨」
9窗边「再在窗边等一场雨」玻璃起潮，旁边多出一条没有门的走廊，雨转回南天
10窗边「走进走廊」电梯停在 0，走廊尽头柜台上放着一顶盔（你少的那顶帽子）
11无门走廊「戴上」结局卡出现，当晚的路线回来了，你听见自己的口气变了

这条链到的是「戴上」。同一个走廊上还有一个「不戴」，它要求你已经想起自己的名字，上面 11 步没有去拿名字，所以看不到这个选项。

前 10 步先把名字拿到手，之后绕去走廊。

五、城里的九件事（决定结尾那段话的长度）

结尾那段话会按你在城里碰过几件事改写：只走该走的那条，读到最短；一件件碰过，读到最长也最具体。下面每项都写清前置，顺序自己安排。

事情在哪做前置
出勤箱城寨口「看出勤箱」→「打开出勤箱」暴雨时在城寨口点「看墙上的湿布」拿到 07；深层口内点「看空盔印旁的涂鸦」拿到切口。三样齐了箱子才打得开。暴雨下巷尾门洞不开，从店门廊「绕到深层口」再「进城寨口」
窗台潮簿理发店「看窗台潮簿」先走过一次回南天的湿门印（读第二遍时字才拆开，有人落在「未归」）
围挡封条柜工地围挡「看封条柜」→「撕开封条」拼出「早产天堂」或开过出勤箱
门缝粮票楼梯 1–7「看门缝粮票」，之后「把酱油放回门缝」；回店里也能「把粮票给陈琛看」无。不想欠人可以点「拒收粮票」，读到的是一句没味道的话
巷顶气根巷中「看巷顶垂须」暴雨那一趟点第二次，且先前听过警告：剪常客时他临走补过「积水太久的巷，别站着」，或者在店里点过「听门口的人」
柜台湿信封理发店「看柜台湿信封」拼出「早产天堂」或开过出勤箱
门廊绿双喜盒店门廊「看挂钩绿盒」先在店里点「听门口的人」（前提：深层口内点过「看空盔印」）。听过之后回门廊再点一次绿盒，忌讳才对上人
空街塔吊空街「仰望塔吊」无，进得去空街就能读
陈琛的手腕理发店「问陈琛的手腕」给常客剪过头发、他离开之后

六、串起来才开门的三处：两块残片、早产天堂、三方摊牌

残片（暴雨）：店里「等到暴雨」→「出门」→「绕到深层口」→「进门」，在口内依次点「看空盔印」「看空盔印旁的涂鸦」「看壁上的霉」「再在口里等一场雨」「捡起墙上残片」→「出门」→ 在口外点「捡起地面残片」→「回店门廊」→「回店」→ 点「在手账里拼残片」。手账写出三个字：早产天堂。

  • 口里的残片只在暴雨当场浮出；雨一小，你人和口一起收回，只剩口外那块。
  • 只有一块时点「试着拼残片」会得到「撕口还缺一块」。

07：暴雨时走到城寨口点「看墙上的湿布」，字泡开成 07；回店里点「把编号给陈琛看」，他说出「霓虹浮游。07」。

湿门印（回南天）：店里「等到回南天」→「出门」→「进巷」→「走到巷尾」→「走进湿门印」→「看门框」，再原路回店。手账出现「以后看店里徽章，别抬头看天」。注意回南天里城寨口往上的楼梯像少了一截，八楼那一阶还是要中雨才在。

三方摊牌：拼出早产天堂、走过湿门印、椅子上没有客人时，在店里点「听三方把话说完」。这一段把「戴上」和「忘掉」两边的要求摆到你面前，陈琛不替你选。

七、店里的三个人与剪发手感

椅子上会依次坐来人，同一时间只有一位：常客（知道中雨门洞之后）、同伴（把编号给陈琛看过之后）、头发还在滴水的人（走过回南天湿印之后）。出现「按住落剪」时按住推进、松手停住；条上有一段绿色范围，落在带里大约是按住 0.65 到 1.1 秒。

  • 剪短、剪够、剪过头，客人给你的半句不一样，三种落点都能拿到那句话。
  • 不换雨、不出门、直接坐着不动也行；客人走时会留一句，信息照样到手。想凭手感落剪，按剪发框里的「收起范围」把绿色范围收掉。
  • 常客剪完后可以点「让陈琛给你修一下」给自己修一次——镜子里还是你，没有新的记忆涌上来。也可以点「把迷茫剪掉」，陈琛会把剪刀放回布里。

八、结尾之后还有一段

  • 点了「不戴」，人直接回到店里，可以马上点「再坐一会儿」，读到店内尾声。这段只给一次。
  • 点了「戴上」要回店里，得自己走出去：「退回窗边」→（雨不是暴雨时先「等到暴雨」）→「退回空街」→「等到中雨」→「退回围挡」→「回店门廊」→「回店」→「再坐一会儿」。
  • 结局卡上有一行「这一趟你碰过的事：X / 9」，合上卡片写着「合上，再走一会儿」——关掉卡片不会丢进度，城里的路照走。想看清另一口气，回店里点「跟陈琛闲话一句」，那句也随结局变。

九、卡住时看这几条

  1. 城寨口回不去：只有中雨和回南天门洞在。雨被改成晴或暴雨时人会回到店里，手账里的字还在。
  2. 八楼那一步上不去：先回店里等到中雨，再走到七楼转角点一次「看踏步」，霉指了才有「踏上那一阶」。
  3. 深层口内进不去：只认暴雨。雨一小就被送出口外。
  4. 空街进不去：只认中雨；窗边只认暴雨。空街和窗边都能就地换雨，跑回店里浪费时间。
  5. 走廊一直不出现：窗边要先点「看窗上的霉」，再点「再在窗边等一场雨」；两步都做完，走廊才在。
  6. 看不到「不戴」：先上八楼想起名字。没想起名字时，盔前只有「戴上」。
  7. 箱子打不开：07（暴雨看湿布）和切口（深层口内看涂鸦）缺一个。
  8. 绿盒读了两遍还是「怪挂件」：先回店里点「听门口的人」。
  9. 潮簿字还是叠着：先走一趟回南天的湿门印。
  10. 手账一直只有四条：正常的，剩下排在后面，做完一条腾出位置。
