一、选题是怎么定下来的

起点不是「我想写一个高考故事」，而是一个更抽象的问题：当代学生的共同记忆——中式教育、高考、复读、封闭、对未来的焦虑——能不能用魔幻现实主义的方式写。 要求是三条：基调像《诺科》，空间像中部工业城，陌生化的手法像瑞瓦肖，但不出现任何真实名称。

要解决的核心困难是：这些记忆离读者太近，写实就变成控诉，抒情就变成怀旧，加设定又容易变成奇幻。最后是靠下面三个判断把它钉住的。

判断一：工厂语法 = 学校语法

陌生化不需要发明新语言。厂办学校当年与厂区共用同一套汽笛与班次——共享作息意味着共享词汇，这是史实而不是比喻。所以只要把教育系统的词整批换成工业用语，陌生化就自动发生：

出厂考 / 判废 / 回炉 / 回炉件 / 序位 / 试压 / 出厂名录 / 静置期

换完发现一个额外好处：这套词表不需要向读者解释。一个人听见「判废」不用先学，就知道那是什么意思，也知道那不是在说人。

判断二：三代人都没错

家庭冲突不写成代沟。祖父认为「这里曾经重要」，父母认为「还能再缓一缓」，主角认为「没有以后」——三个判断在事实上同时成立。真正压人的不是谁错了，是判断力和无力感一起长。

由此多出一条写作纪律：不给任何人反派位置。父母也是被换算过的人（被判过的，或靠侥幸留下的），他们是幸存者，不是恩人。幸存者的爱里带恐惧，不带账。 收束因此不能是两清，而是「母亲听不懂孩子那句话，仍然给他盛饭」。

判断三：五条反模式，按危害排序

反模式为什么危险
怀旧一旦开始怀念，作品就站到「过去更好」那边，而这座城的问题恰恰是过去就没好过
债务语法把父母写成恩人，故事就变成还债，冲突降格成孝道
给出路让主角成功出厂＝承认判定有效，作品价值归零
锈带美学把贫穷拍好看，等于替制度做美陈
方言当风味地方话变成装饰，人变成土特产

这五条不是写作时的小心，是后面推翻整个美术方案的原因——见第二节。

定稿的一句话，和一个检验法

一个被判过两次不合格的人，决定在第三次考试那天，去给一座没人再用得上的汽笛上油。

检验法：把「上油」换成任何别的动作，故事立刻散架。 因为这个动作同时是四件事——信仰的物理形态（不是旗帜、不是照片、不是遗物，是一件还在用的工具）、世界的运行机制（汽笛会响是因为有人上油，规则不需要魔法就能落地）、父子之间唯一不需要语言的通道，以及一件可以被继承的无用之物。道具立不住的地方，设定也没立住。

与已有作品的边界

这个工作区里另有一个世界观《雨底之东》，走的也是「音译 + 地理分区」的陌生化路线。两者被判为可共享方法论、不可共享设定：《雨底之东》的变形来源是自然（雨），余埠的变形来源是制度（判定）。方法论可以复用，具体设定一律不借。

二、为什么最后是黑白木刻

因为第一版是错的，而且错在我自己写下的规则上。

第一层：v1.0 犯了世界观明令禁止的事

初版做的是彩色构成主义，八色语义化色板：锈红、泡白、窗黄——八个色里五个暖色。而《世界观基调》的反模式第一条写着：不许滑向锈带美学。

暖色会让人怀旧。而这座城最不该做的事，就是让人怀旧。

暖色是一种安慰。这部作品不该安慰人。

审稿时被指出「画风和色调不太对，或许纯黑白色调更好，有点墨水屏或版画质感」——判断是对的，但它暴露的问题比色调更深：我在色板上犯了这个世界观自己明令禁止的事。 所以不是把颜色调冷，是整份重写。

第二层：「红＝制度」是个偷懒

用颜色告诉观众「这是判定系统」，等于直接发标签。制度在现实里从来不是红的，它只是太整齐了：等距、规整、没有手迹的重复。黑白没有颜色可用，于是这一条只能靠形表达，反而更准。

落到规范里就是一句可校验的话：凡是制度的产物，边缘必须绝对等距、绝对平行、绝对没有手迹；反过来说，凡是有人的东西，边必须毛。「整齐本身就是压迫」这一条后来一路贯穿到 UI——按钮边、分隔线、选项短横，全部零误差。

第三层，也是真正的理由：凿 = 擦

黑白木刻的工艺是从板上凿掉。故事的伦理是把它从表上擦掉。

主角不争取、不翻案、不改判——他只是让一样东西不再出现在表上。凿 = 擦。

所以这不是审美偏好，是找对了媒介。彩色的时候这是个「一座锈红色的城」的故事；黑白木刻的时候，这是个「一块被凿掉很多的板」的故事。 后者才对。

第四层：一个技术上的意外收益

原方案里有一句约定——「生图会风格漂移，所以主画面走手写 SVG」。黑白把这条约定变成了物理限制：只有黑与白，漂不到哪去。而且原本非生图不可的三项纹理，在黑白里全部能由排线和纸纹做出来：泡白的纸＝排线变疏且线边发毛；锈＝交叉线加断口；雨＝白色细斜线。

顺带纠正一处画反的地方：雨在黑白里是白的，不是灰的——因为雨是纸露出来的地方。最终成品零生图、零外部资源、双击即可运行。

三、这套画法怎么落到代码里

规范里最关键的一句是：这套画法不是风格，是工艺。 风格可以自由发挥，工艺只能是纪律。下面五条是真正约束住成品的部分。

1. 只有一个墨、一个纸，灰是墨的密度

墨 #0D0C0B（不是纯黑——纯黑是屏幕的黑，墨是有油的黑），纸 #F2F0EB（不是纯白——纯白是光源，纸是反射）。没有第三色。灰色不是颜色，是墨的密度。

因此有一条技术纪律：任何明度都必须用线的密度做出来，不许用 opacity 造灰，不许用 fill 填灰——因为木刻里没有半透明的墨，只有刻得多和刻得少。唯一允许 opacity 的地方是纸纹层，因为它模拟的是纸，不是墨。

墨阶分七级（疏 / 略密 / 中 / 密 / 交叉 / 极密 / 满版墨），纪律三条：一屏最多用四级；相邻两级不能差超过两级；实心墨一屏最多一处，且必须是最重的那一处——它就是原来那个「亮红」，只是反过来：不是最亮的一处，是最重的一处。

2. 块面，不是轮廓

物体是一块墨，白只出现在被凿掉的地方。一只壶是一块黑，不是一根壶的线；一只手是一块黑，不是五根手指的线。自检标准很土但有效：白线加起来超过画面 1/5，就是在画线描。

3. 边要毛

机器画的线均匀，刻出来的线不均匀。每 6–10 条线里要有 1 条明显的粗细不匀或断口。 做法是不用连续线段，用 2–3 段首尾相接、笔宽略有差异的短段，或在长线上叠一道短白口当「刻崩了的地方」。

这条不做，画面就还是矢量图。它是全篇唯一必须靠手工痕迹完成的事——所以成品里手刻的图元是逐条写的，不是 pattern 铺出来的。

4. 光是减出来的

在这个媒介里，光不是加上去的，是墨没有到达的地方。窗亮着＝那一小块纸没被刻到；月亮＝纸留着；汽笛响时全城亮起＝屏幕上成片地出现白。

这一条不是画面装饰，它直接改写了三场：「全城的灯一盏一盏亮」不画灯泡，先把夜空铺满密排线，再用白块把窗一个个挖出来；掀榜那层的「泡白」不调色，画成排线变疏、线边发毛、有断续（那是墨被二十年雨水冲掉的样子）；最后一屏「静置」整屏只剩一根铅笔线和一片白——因为静置的意思是「不再加工了，从流程里拿出去」，画面跟着一起被拿空。这三条在彩色方案里想不到，也不可能有。

5. 全片只有三样东西会动

指针（抖、掉、稳住，抖幅随油量递减而增大）、窗（一盏一盏亮，其实是白块出现）、汽笛（响时整幅位移 2px 再归位，唯一允许用「错版」的地方）。其余全部静止，包括人——人物动作靠换图，一秒一帧的硬切，不做补间。

这条的价值在于：当只有三样东西会动，动的那一秒就是全部的信息量。玩家会在第三次之后开始盯着指针看，那时候机制才真正开始工作。

UI 的三条自律

  • 不给数字。油量、序位、剩余次数，界面上一个数字都不显示，只靠液面高度、指针位置、壶的重量。
  • 选项会消失，不置灰。说过的话，那个选项直接消失、位置留空。不写「已选择」，不留删除线——消失就是消失，玩家自己会记得那里本来有一个。
  • 不显示「▼」。推进提示是光标位置一根竖线，闪 2 次/秒。

另有一条只在两处使用的工艺：错版。真实套色木刻会有套印偏移，单色木刻常是印两遍——第二遍略偏，产生重影。只在汽笛响的那一秒和最后一屏用，偏移量不许超过 3px，再多就是印刷事故，不是表现。

规范是被脚本守着的

规范里的 16 条禁止清单（出现第三色、用 opacity 造灰、白线勾轮廓、出现人脸、横贯全宽的地平线、渐变发光投影模糊、向上冲的斜线、手写体书法体、一屏超过四级墨阶、错版超过 3px……）已经写成校验脚本，对每个场景逐个几何检查。

当前状态：24 个场景 / 0 违规 / 0 脚本异常；全剧 12 条分支路径跑通 36 屏，0 异常。

四、没做到、也没验的部分

这份规范是按「1920×1080、每场景独立 .svg 文件、单场景 < 40KB、共享 ink.svg 定义库」写的技术规格，成品不是那个形态：为了让双击就能玩、零外部资源，压成了单文件、1200×560 一屏一组 SVG，七级墨阶和纸纹在文件内定义为 pattern。这是取舍，不是达标。

另外四项是规范里自己标着「未验」的风险，成品也没有补齐：

  • 白天场景没验。所有测试样张都是夜。白天意味着大面积留纸，画面会不会变空、变轻、失去压迫——这是黑白独有的风险（彩色时白天还能靠暖调压住），也没做过白天／夜场的对照稿。
  • 雨是推理，不是证据。判断「雨在黑白里是白的」，理由是雨是纸露出来的地方；但只做了一屏（雨中那面墙），没做灰雨对照。
  • 两个人以上同框没解决。规范写了「同一画面出现两个人时，取景必须来自不同系统：一个给后颈，另一个只给手」——但这条只靠文字纪律约束，没有可靠画法。黑白把人变得更抽象，却没有解决「两个人分不清」。
  • 最后一屏的纯白收尾想法在规范里，成品还没做到那个强度。
